# Claim Evidence Matrix Template

Use this template to keep conclusions evidence-based.

| Claim | Evidence Type | Source / Artifact | Supports | Contradicts | Notes |
| --- | --- | --- | --- | --- | --- |
| Example claim | Paper / run log / figure | `path-or-citation` | `yes/no` | `yes/no` | Add only conservative conclusions |

## Rules

- Do not mark a claim as novel unless competing work has been checked.
- If evidence is insufficient, write: `Insufficient evidence to support this claim.`
- Keep claim language conservative and specific.
